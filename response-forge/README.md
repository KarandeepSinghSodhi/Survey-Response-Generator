# ResponseForge

This folder contains a Next.js frontend demo for the synthetic survey generator.

## Local development

```bash
cd response-forge
npm install
npm run dev
```

Open the site at `http://localhost:3000`.

## Features

- Generate 200 synthetic e-commerce survey responses in the browser
- Built-in report page with charts for category mix, delivery reliability, and satisfaction
- Response explorer with search and row details
- Designed for deployment on Vercel as a static React app

## Vercel deployment

This folder includes a Vercel configuration file for a clean deployment.
Deploy the app by selecting this folder as the project root in Vercel.
